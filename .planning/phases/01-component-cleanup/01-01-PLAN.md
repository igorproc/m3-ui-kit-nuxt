<objective>
Refactor the AppBar component structure and styling.
1. Migrate hardcoded heights and styles to a nested, Zero-Runtime hierarchical Sass map ($tokens) in a new `app/assets/stylesheet/components/app-bar/_index.scss` file.
2. Replace static grid area layouts in the Vue component with responsive computed grid template areas driven by active slots.
3. Expose a container slot acting as a full layout override, bypassing the default template grid.
4. Integrate the dynamic `--ui-app-bar-height` CSS variable into Vue useLayoutItem so height calculations are resolved entirely in CSS/SCSS.
5. Apply smooth CSS animations and elevation transitions triggered by a reactive `isScrolled` boolean prop.

Purpose: Align the AppBar component with Material Design 3 guidelines, improve rendering performance, and establish a decoupled layout architecture in the UI Kit.
Output: Two refactored files: SCSS stylesheet and Vue component.
</objective>

  <name>Task 1: Create AppBar SCSS Token Map and BEM Stylesheet</name>
  <files>app/assets/stylesheet/components/app-bar/_index.scss</files>
  <action>
    Create a new file `app/assets/stylesheet/components/app-bar/_index.scss` (per D-01).
    Define a hierarchical `$tokens` map mapping Material Design 3 tokens to standard `$theme-color-link`, `$theme-shape-link`, and `$theme-typography-link` keys using `map.get()`.
    Include the global `--ui-app-bar-height` token (per D-02) within the stylesheet.
    Implement BEM-compliant classes:
    - `.ui-app-bar`: Uses `material-map` and `generate-tokens` mixins to generate CSS properties dynamically with prefix `ui-app-bar`.
    - Apply base grid styles, inline padding, block padding, gap, border-radius, background-color, and box-shadow.
    - Implement transition effects for `background-color`, `box-shadow`, and `min-height`.
    - Implement BEM modifiers for heights based on variant and subtitle presence:
      - `--center-aligned`: sets `--ui-app-bar-height` to `height-center-aligned`.
      - `--small`: sets `--ui-app-bar-height` to `height-small`.
      - `--medium`: sets `--ui-app-bar-height` to `height-medium`, or `height-medium-with-subtitle` if the component has a subtitle (using secondary modifier `--with-subtitle`).
      - `--large`: sets `--ui-app-bar-height` to `height-large`, or `height-large-with-subtitle` if the component has a subtitle.
    - Implement dynamic scrolling modifiers:
      - `--scrolled`: transitions the background color and box shadow to their scrolled configurations.
    - Implement child elements layout:
      - `__nav`: standard M3 offsets and margins.
      - `__title`: flex-direction column, correct typography specs using `apply-typography` mixin.
      - `__actions`: flex alignment and offset.
  </action>
