Пиши код, потом один раз в конце (упало — чини и повторяй только упавшее, не больше двух раз):
```
npx vitest run <твои папки/спеки> --coverage.enabled=false
npx eslint <твои файлы и папки>
npx stylelint <твои .vue и .scss>
npm run lint:scss                      (ошибки в чужих файлах — игнорируй, их правят параллельно)
npx playwright test playground/fixtures/<твоя фикстура> --output test-results/p2/<группа>
```
Dev-сервер уже запущен на :3200 (`playwright.config.ts` его переиспользует) — свой не запускай. Параллельные
правки дают HMR-перезагрузки: упавший e2e перезапусти один раз, прежде чем считать падением. Новую **папку**
фикстуры сервер не видит — `touch playground/app/utils/fixtures.ts`; новый файл в существующей папке — тоже
нужен `touch`. `npx vue-tsc --noEmit` — один раз в конце, если менял публичные типы; разбирай только ошибки в
своих файлах (известные чужие: WIP-демо `playground/app/demo/**`, `fixtures/timeline/matrix.vue`). Полный
`npm run test`, `build`, prod-e2e гоняет оркестратор.
