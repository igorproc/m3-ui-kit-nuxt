Нового пропа нет, слот `{ selected }` остаётся | `decisions.md` W70-А; потребитель кладёт `MIcon` в слот, имя глифа знает только он — контекст не меняет API, первый кадр SSR верен (provide/inject на сервере) |

Клавиши строки остаются потребителю. Page-клавиши не тронуты | Chromium двигает по Home/End только блочную ось (аудит); своя клавиатурная модель строк по-прежнему у потребителя |
| ICON-1 | Dev-предупреждение о неизвестном, но корректном имени | Только на dev-сервере при SSR и только для набора `ic`: `utils/icon/knownGlyphs.ts` читает локальный `@iconify-json/ic` (зависимость кита), динамический импорт под `import.meta.dev && import.meta.server`; имена других коллекций не судятся. В браузер данные набора не попадают; SPA без SSR получает только предупреждение `@nuxt/icon` | Без новых зависимостей и сетевых запросов (условие пункта); набор `ic` — 4 МБ, тащить его в клиент нельзя |
| ICON-2 | Стили `.iconify` / `svg` | Класс кита `ui-icon__glyph` на `<icon>` (проходит на корень глифа `@nuxt/icon` через fallthrough); правило задаёт `1em`, `fill`, `font-size: inherit`, forced colors. Размер `1em` теперь получает и CSS-глиф до загрузки (раньше — только `svg`): занимает тот же квадрат обёртки, вид не меняется | BEM без тег-селекторов и чужих классов |
| APP-1 | `.ui-app__overlay-host > *` | Не менял | `decisions.md` «Принятые исключения … `> *` в `app __overlay-host`» (2026-10-23); все поверхности кита сами ставят `pointer-events: auto`, правило нужно только для контента потребителя, телепортированного в хост. Альтернативы меняют контракт: без правила такой контент становится некликабельным, хост нулевого размера меняет его containing block |
