# Журнал решений — overlays (фаза 2, 2026-10-30)

Оркестратор сводит строки в `docs/system/{ru-RU,en-US}/decisions.md`.

| ID | Пункт | Решение | Основание |
|---|---|---|---|
| OV-01 | dialog Ш2: разделители над и под телом | `__content` всегда несёт `border-block: max(1px, 1rem) solid transparent` (ключ `divider.thickness`); под `@supports (animation-timeline: scroll())` две анимации на `scroll(self block)`: верхняя линия проявляется за первые `spacing(16)` прокрутки, нижняя гаснет за последние (`animation-range`, ключ `divider.reveal`), цвет `outline-variant`. Тело без прокрутки — таймлайн неактивен, линий нет. Паузы сохранены: `headline.margin.block.end` = `calc(16rem − волосок)`, `actions.margin.block.start` = `calc(24rem − волосок)`. Без поддержки scroll timeline — без разделителей | План («прогрессивное улучшение, без JS и без рантайм-переменных»), правило «производные в карте»; волосок `max(1px, 1rem)` — принятое исключение (как у `MDivider`) |
| OV-02 | dialog / sheet LY-10 | Физические `width` / `height` / `margin` → логические (`inline-size`, `max-inline-size`, `max-block-size`, `min-block-size`, `margin-block` / `margin-inline`); ключи карт переименованы по свойству: `max.inline-size`, `max.block-size`, `min.inline-size`, `drag.handle.inline-size` / `block-size` | Правило кита «новый код — на логических свойствах»; карта зовёт значения именем свойства |
| OV-03 | sheet Ш6: порог 56 + скорость | `swipeThreshold` — в rem, по умолчанию 56 (было 80 px). Решение на отпускании (`utils/overlay/swipe.ts`): короче slop 8 rem — не свайп; скорость к краю ≥ 125 rem/с (по сэмплам последних 100 мс) — закрыть при любой длине; взмах обратно ≤ −125 — вернуть даже за порогом; иначе — по порогу. 125 и 8 — константы M3 (`ModalBottomSheet` velocity threshold, touch slop), не пропы. Общее для всех `closeOnSwipe` (лист, drawer) | Plan sheet Ш6 и строка токенов (`PositionalThreshold` 56, `VelocityThreshold` 125); правило «всё в rem»; направление взмаха важнее позиции — как `AnchoredDraggable` в Compose |
| OV-04 | tooltip: серверный HTML через слот-пропсы ссылался на несуществующий id | `triggerProps` пуст до `onMounted`; авто-связь тоже ставится в `onMounted`. Сервер и первый кадр гидрации — без `aria-describedby` (ни одной ссылки на отсутствующий узел, гидрация без расхождений); с монтирования поверхность в DOM и связь постоянна. Скрытый текст описания в SSR отвергнут: дублирует текст и противоречит Q19-В | Q19-В («поверхность в DOM с момента монтирования, связь постоянная») + правило «первый кадр SSR верен»: битая ссылка — неверный первый кадр |
| OV-05 | tooltip Ш3-пусто | Без содержимого (`text`, слот `content`, у rich — `subhead`) бэг пуст, авто-связь снимает только свой id (чужие в `aria-describedby` остаются); с появлением содержимого связь возвращается | План: «пустой текст — `show()` ничего не делает, связь не ставится» |
| OV-06 | tooltip Ш6 (найдено e2e) | Короткий тап показывал тултип навсегда: после тапа браузер шлёт совместимые `mouseenter`, `mouseleave` не приходит. Обёртка запоминает `pointerType` из `pointerenter` / `pointerdown`; `mouseenter` после касания не показывает. Мышь и перо — как раньше. Долгое нажатие — без изменений | W39-А и `behavior.md` («на таче — долгое нажатие»); e2e `tooltip.e2e.ts › a short tap does not show it` упал до правки |
| OV-07 | overlay Ш3: страховочная прокрутка панели (CT-10) | Только modal: `align-items: safe center` за `@supports` (без поддержки — `center`, как было) и модификатор `ui-overlay__panel--scrollable` (`overflow: hidden auto`, `overscroll-behavior: contain`) только в статусе `open`. Во время входа и выхода — без прокрутки: выезжающий лист / drawer на время перехода выходит за панель и показал бы полосу прокрутки. `margin-block: auto` у детей из плана отвергнут: перебивает `align-self: flex-end` листа и спорит с `margin` диалога порядком CSS | План overlay Ш3; правило «нативное — за feature-detection со своим фолбэком»; память «Prod CSS order» |
| OV-08 | overlay Ш5 TH-11 | `scrim.contrast.more.opacity: 50%` в карте, `@media (prefers-contrast: more)` на `__scrim` | План overlay, строка токенов «Высокий контраст» |
| OV-09 | `useOverlayDismiss` EN-10 | `window keydown` (через `useGlobalListener`) и click-outside (`pause` / `resume`) живут только пока `isOpen`; снимаются и при уничтожении области | Тот же приём, что у меню (`ui/menu/index.vue`), `report.md` §8 |
| OV-10 | modals `open(component, { props })` | `$material.modal.open` перегружен: компонент → одноразовая модалка (`ModalOpenOptions`: `props`, `slots`, `parent`), `Promise<ModalResult>`, после закрытия хэндл уничтожается; строка → открыть зарегистрированную по id (как было). Без `parent` — корневая | Имя `open` из плана (`<service-api>`), id-путь сервиса уже в API — перегрузка ничего не ломает |
| OV-11 | modals `closeTop(reason)` / `closeAll(reason)` | Причина по умолчанию `programmatic`; оба закрывают и `persistent`. `closeTop` — последняя по порядку открытия модалка с `isOpen()`. Причина доходит до результата через владельца: хэндл (`createModalHandle`) рисует компонент в обёртке, которая провайдит `ModalOwner`; первый модальный `MOverlay` внутри забирает его (`claimModalOwner`, вложенным — `null`) и регистрирует; реестр закрывает такую запись через хэндл с причиной | W43-А («программное закрытие выражает намерение приложения»); план `<nesting>` («Escape / closeTop — только верхний») |
| OV-12 | modals: конкурирующие события | Один ответ на открытие — первый: `confirm` / `cancel` после ответа и `close(reason)` / `closeTop` уже не меняют результат. Приоритет: ответ > причина `close` > `parent-closed` > `programmatic` | План `<tests>` («promise завершается ровно один раз»); `useModalResult` у `MDialog` / `MSheet` уже держит один ответ — хэндл теперь тоже, для произвольных компонентов |
| OV-13 | `useModal` → `createModalHandle` | Машинерия хэндла вынесена в `composables/modal/createModalHandle.ts` (без Nuxt-контекста), `useModal` — тонкая обёртка (родитель из `inject`, сервис из `useNuxtApp`); `close(reason?)` у хэндла | Сервису нужен тот же хэндл вне компонента; `useModal.ts` иначе вырос бы за 400 строк |
| OV-14 | `fixtures/overlay/matrix.vue`: меню на голых `button.ui-menu__item` | Переведено на `MMenuItem`: меню (группа menu) теперь ищет пункты по роли, и голые кнопки ломали axe (`aria-required-children`) и стрелки в `overlay.e2e.ts` | Q14-А; фикстура — моя, меню — нет |
