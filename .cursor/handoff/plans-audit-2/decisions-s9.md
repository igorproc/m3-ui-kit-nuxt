# Plans audit 2 — фаза 2: решения S9 «общий контракт ветки `selected`» (2026-10-30)

| ID | Пункт | Решение | Основание |
|---|---|---|---|
| S9-01 | Форма контракта | Выбор — ветка `selected`, противоположность — `unselected`; внутри только `container` (заливка, трек, индикатор, таблетка, коробка флажка), `content` (глиф, подпись, ручка, кольцо радио) и `shape` (то, что выбор меняет в форме или размере). Взаимодействие — подкарта `active` внутри своей части с теми же ключами (`content.active.color`, `container.active.border`); тон слоя состояний — `content.active.layer.(color\|pressed)`. Отключённое — `disabled.selected` / `disabled.unselected` того же состава; у частей компонента — `<часть>.disabled.selected` (`day.disabled.selected`). | решение владельца «полный контракт»; эталон — `button/_schemes.scss`, `button/segmented/_index.scss`; Compose `*Selected*` / `*Unselected*` |
| S9-02 | Семья выбора (`choice/_control.scss`, `control-tokens`) | Цвета слоя 40 переехали из `state.layer.color.{rest, pressed, selected, selected-pressed, error}` в `unselected\|selected\|error.content.active.layer.{color, pressed}`; прозрачности остались в `state.layer.opacity.*`. Миксин `layer` читает новые пути. Слой — в `content`, а не в `container`: у M3 радио — одна иконка, у switch слой стоит на ручке; флажок идёт за семьёй, чтобы у общего миксина был один путь. | Compose `CheckboxTokens` / `RadioButtonTokens` / `SwitchTokens` (`Selected/Unselected/Error*StateLayerColor` — по сторонам) |
| S9-03 | checkbox | Коробка — `container`: `selected.container.color`, край невыбранной — `unselected.container.border`, его тон под указателем, в фокусе и нажатии — `unselected.container.active.border`; галочка — `selected.content.color`. Ошибка — `error.container.(color\|border)`, `error.content.color` (ключ `border` добавлен с тем же значением, что `color`: край ошибки и заливка выбранной ошибки — разные свойства). Отключённое — `disabled.unselected.container.border`, `disabled.selected.container.color`, `disabled.selected.content.color`. `control.border` оставил только `width`. | Compose `CheckboxTokens` (`SelectedContainerColor`, `SelectedIconColor`, `UnselectedOutlineColor`, `UnselectedHoverOutlineColor`, `Error*`) |
| S9-04 | radio | Кольцо и точка — `content` (контейнера нет): `unselected.content.color`, `unselected.content.active.color`, `selected.content.color`, `error.content.color`. `disabled.control` разделён на `disabled.unselected.content.color` (кольцо, базовое правило) и `disabled.selected.content.color` (точка) — значение одно. `outer.border` оставил только `width`. | Compose `RadioButtonTokens` (`SelectedIconColor`, `UnselectedIconColor`, `UnselectedHoverIconColor`, `Disabled*IconColor`) |
| S9-05 | switch | Трек — `container` (`color`, `border`), ручка и её глиф — `content` (`color`, `icon`, `active.color`), размер ручки — `shape.thumb` (16 / 24). Коробка ручки и ручка с глифом читают `selected.shape.thumb`: коробка — это бокс выбранной ручки, а правило `--checked, --icon` одно, разбить его — сменить CSS. Нажатая 28 — `thumb.pressed.size` (одна на обе стороны). Свои `layer.color.{off,on}` удалены — те же значения уже дают `control-tokens` (`*.content.active.layer.color`). Ошибка — `error.container.border` и `error.content.active.layer.color`. | Compose `SwitchTokens` (`Selected/UnselectedTrackColor`, `*HandleColor`, `*IconColor`, `Selected/UnselectedHandleWidth`, `PressedHandleWidth`) |
| S9-06 | fragments/navigation-item | Active* → `selected`, Inactive* → `unselected`: заливка индикатора `indicator.color` → `selected.container.color`; подпись `active.label.color` → `selected.content.color`, иконка `active.icon.color` → `selected.content.icon`; базовый цвет `color` → `unselected.content.color`, наведение `hover.color` → `unselected.content.active.color`; `drawer.active.color` → `drawer.selected.content.color`. Не тронуты `indicator.state.*` (слой общий для обеих сторон) и `disabled.color` (для любого пункта). | Compose `NavigationBarTokens` / `NavigationRailTokens` (`ActiveIndicatorColor`, `ActiveIconColor`, `ActiveLabelTextColor`, `Inactive*`) |
| S9-07 | button/segmented | Роль — внутри части: `selected.<role>.container` → `selected.container.color.<role>`, `selected.<role>.content` → `selected.content.color.<role>`. `unselected.content.disabled.color` → `disabled.unselected.content.color` (базовое `:disabled`), `disabled.content.color` → `disabled.selected.content.color`. | состав контракта; эталон — роли кнопки вне ветки, здесь роли внутри, поэтому — уровнем ниже части |
| S9-08 | chip | Листья `label.selected`, `icon.selected`, `icon.input-selected` и ветка `selected.(color, hover)` → `selected.container.color`, `selected.container.elevation.hover`, `selected.content.color`, `selected.content.icon.color`, `selected.content.icon.input`. `disabled.container` (общий для elevated и выбранного) не тронут. | Compose `FilterChipTokens` (`FlatSelectedContainerColor`, `SelectedLabelTextColor`, `SelectedLeadingIconColor`, `FlatSelectedHoverContainerElevation`), `InputChipTokens.SelectedLeadingIconColor` |
| S9-09 | color-picker | `swatches.selected.(ring, width, focus-offset)` → `swatches.selected.container.ring.(color, width)`, `swatches.selected.container.focus-offset`; `swatches.selected.check.(size, on-dark, on-light)` → `swatches.selected.content.size`, `swatches.selected.content.color.(on-dark, on-light)`. | кольцо — край выбранного образца, галочка — содержимое |
| S9-10 | date-picker | `(day\|year).selected` и `(day\|year).disabled.selected` с `(container, color)` → `container.color`, `content.color`. `today` / `current` не тронуты. | Compose `DatePickerModalTokens` (`DateSelectedContainerColor`, `DateSelectedLabelTextColor`, `SelectionYearSelectedContainerColor`, `SelectionYearSelectedLabelTextColor`) |
| S9-11 | list/item | Разбросанные `*.selected.color` и `container.selected.(color, shape)` → `selected.container.color`, `selected.shape`, `selected.content.(label\|supporting\|overline).color`, `selected.content.leading.icon.color`, `selected.content.trailing.(icon.color\|supporting.color)`. Ключи по частям сохранены (не слиты в один цвет), чтобы части оставались настраиваемыми порознь. | Compose `ListTokens` (цвета и угол выбранного пункта — одной группой Selected) |
| S9-12 | menu | `item.shape.selected` → `item.selected.shape`; цвета выбранного пункта уже были по контракту в `variant.*.selected` (по варианту). | состав контракта |
