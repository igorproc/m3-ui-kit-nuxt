# Журнал решений — navigation, фаза 2 (2026-10-30)

| ID | Пункт | Решение | Основание |
|---|---|---|---|
| NAV2-01 | app-bar, safe-area вне `m-layout` (RS-09) | Вырез берёт только прибитый бар (`sticky`) вне раскладки (`useLayoutZone() === null`): модификатор `ui-app-bar--safe-area` — `box-sizing: content-box`, `padding-block-start: env(safe-area-inset-top)`, боковые `calc(4 + env(left/right))`. Внутри `m-layout` вырез отдаёт зона (carve), бар ничего не добавляет — без двойного счёта. | План: «когда бар прибит к верху окна»; carve тоже даёт вырез только sticky-зоне. `content-box` оставляет высоты размеров (64/72/112/136/120/152) высотами содержимого — без дублирования правил высоты, сворачивания и keyframes. |
| NAV2-02 | navigation-bar, safe-area вне `m-layout` (Ш4) | Вне раскладки бар всегда берёт нижний и боковые вырезы: `padding-block-end: env(bottom)`, `padding-left/right: env()` (у Centered — `calc(поле% + env)` из карты), `min-height: calc(64 + env(bottom))`; `border-box` сохранён. Внутри `m-layout` (зона или контент) — ничего. | План Ш4 / RS-09. `border-box` — бару задают ширину (`width: 100%`, фикстуры 360/480): `content-box` вывел бы его за контейнер. |
| NAV2-03 | navigation-bar, dev-предупреждение о числе пунктов | Предупреждает вне 3–5 при `iconPlacement: top` и вне 3–6 при `start`; пустой список (загрузка) не предупреждает. | Таблица плана: «3–5 (compact), 3–6 (medium)»; карта `centered` описывает до 6. |
| NAV2-04 | navigation-rail вне `m-layout` | Модификатор `ui-navigation-rail--standalone`: `height: 100%`, `max-height: 100dvh`, sticky остаётся. Внутри раскладки — прежние правила (in-page / in-scroller / hosted / зона). | Аудит: вне раскладки рейл был `100dvh` и игнорировал контейнер (480 → 1200). `max-height` сохраняет прежнее поведение в контейнере без высоты: рейл не выше окна, список скроллится. |
| NAV2-05 | navigation-rail, кольцо крайних пунктов (IN-05) | Скроллящий список получает `padding-block` = ширина + отступ кольца (5rem) и возвращает его `margin-block: -5rem` (`list.ring.*` в карте), во всех режимах. | Тот же приём, что у крошек в scroll (Ш2): пункты не сдвигаются, кольцо не обрезается. |
| NAV2-06 | breadcrumbs, арифметика в `.vue` | `calc(-1 * …)` отступа и маски — в карту: `list.scroll.margin.block`, `list.scroll.fade.offset`, `list.scroll.fade.mask.size`. | Правило «арифметика — в карте»; кроме `:146` те же выражения были у маски края (6 мест). |
| NAV2-07 | pagination, мишень 48 | `@include touch-target(block)` у кнопки страницы; e2e мишеней переписаны под запись: кнопка растёт только по блоку, ряд на таче с шагом 48, зазор между страницами не принадлежит ни одной. | `decisions.md` «Мишень 48»: «кнопка страницы … растут только по блочной оси». Прежние e2e закрепляли обе оси — расхождение с записью, не поведение под решение. |
| NAV2-08 | tabs, минимум 24 у индикатора | `min-inline-size: 24rem` у `ui-tabs__tab-content` primary (`primary.indicator.min-width`): и anchor-индикатор ряда, и собственный индикатор вкладки берут ширину содержимого. | Аудит, вариант А; содержимое центрировано — подпись визуально не сдвигается. Secondary тянет индикатор на всю вкладку (≥ 32). |
| NAV2-09 | tabs, бейдж во вкладке | Миксин `badge-anchor(large / small)` (BadgedBox: large −2 / 12, точка 0 / 6) вместо ключей `badge.large/small` карты; точка — свой модификатор `ui-tabs__tab-badge--dot`, а не `.ui-badge--small` чужого блока. | Формула BadgedBox, как у пункта навигации; BEM без чужих модификаторов. |
| NAV2-10 | tabs, `activeIcon` (S7, W70-А) | `activeIcon` у `MTabItem` и `MTab`; без него выбранная вкладка рисует залитую пару `ic`-глифа (`MIcon filled`); у вкладки-маршрута — по `isExactActive`. Уже в SSR. | Как у навигации (`fragments/navigation-item`). |
| NAV2-11 | tabs, токены (Ш1) | `list.border.width: max(1px, 1rem)`; отступы и промежутки → `spacing()` (52 = `48 + 4`); `content.padding` атомарно (`block` / `inline`). | `decisions.md` «Тонкая обводка»; TK-02 плана. |
| NAV2-12 | toolbar, `hasModel` | Инстанс выбора (`useToolbar`) создаётся всегда; режим модели — `multiple` или привязанный `v-model` (ключ `modelValue` в vnode props через `useBoundProp`, читается в рендере и обработчиках). Модель с начальным `undefined` или привязанная после монтирования включает выбор. | Аудит Ш1 (`index.vue:93`). `useBoundProp` — существующий приём кита (`utils/text-field/supportLine.ts`). |
| NAV2-13 | toolbar, S9 | `layout` → `orientation`, `MToolbarLayout` → `MToolbarOrientation`, класс `ui-toolbar--layout-*` → `ui-toolbar--orientation-*`; без алиаса. | S9 = А (владелец), как у slider; кит 0.x без шимов. |
| NAV2-14 | navigation-drawer, токены | `spacing()` в карте; шорткат шапки `4 8 12` → атомарные `header.padding.block.start/end`, `header.padding.inline`; фолбэки `env(…, 0px)` → `0rem`. | Правило «атомарные значения в карте», только rem. |
| NAV2-15 | navigation-item, токены | Отступы и промежутки → `spacing()`; 6 = `calc(spacing(4) + spacing(2))`; размеры (24/32/40/56/64) остаются литералами rem. | Правило «вне шкалы — calc в карте»; как у семьи кнопок. |
| NAV2-16 | app-bar, navigation-rail, переходы | `transition` читает `container.motion.*` из карты, а не `var(--sys-motion-*)` в `.vue`; высоты рейла (`in-page`, `in-scroller`, `standalone`) — тоже в карте. | Правило «`.vue` только `g()`». |
| NAV2-17 | navigation, фикстура stress | Новая `navigation/stress.vue` (6 пунктов, длинная подпись и слово без пробелов, бейджи 999 и точка, 360, пустой бар, рейл с `#header` и `v-model:expanded`, развёрнутый рейл) и отдельный `navigation/stress.e2e.ts`; `audit-rail-toggle.vue` не тронут. | `navigation.e2e.ts` уже 274 строки — с новыми проверками вышел бы за 400. |
| NAV2-18 | navigation-bar, проверка dev-предупреждения | Проверяется e2e по консоли dev-сервера (`test.skip` в CI: прод-сборка вырезает `import.meta.dev`); unit не пишется. | В Vitest `import.meta.dev = false` — конвенция кита (`… a11y.spec.ts`: «guarded by import.meta.dev»). |
