# Sweep run 2 · G3 (навигация, layout, оболочка, иконка) — решения

Для переноса оркестратором в `docs/system/{en-US,ru-RU}/decisions.md`.

| Пункт | Решение | Причина |
|---|---|---|
| Q20-А, значения на `html` | Внешний `m-layout` пишет на `html` все четыре `--m3-layout-inset-*` по диапазонам. Блочные края — то, что достаёт до окна: в `full-height` все top/bottom зоны, в режиме скролла страницы только прибитые (sticky с размером). Боковые — суммы `start`/`end`. Вложенный layout на `html` не пишет. Внутри layout-элемента те же имена — полные суммы, как раньше | Снекбар и прочее в overlay-host живут вне layout-элемента. In-flow футер уезжает со скроллом: если бы он входил в инсет, снекбар висел бы над пустым местом |
| Q20, вырез | `--m3-layout-inset-bottom` на `html` содержит нижний вырез, только когда прибитая нижняя зона стоит у края окна | Так считает carve; снекбару рекомендован `max(inset, env(safe-area-inset-bottom))` |
| Кнопки страниц `MPagination :disabled` | `softDisabled` (`aria-disabled`, кнопка в Tab-порядке). Слот `#item` отдаёт `props['aria-disabled']` и верхнеуровневый `disabled` для вида — как first/prev/next/last | Нативный `disabled` на нажатой странице выбрасывал фокус на `<body>` на всё время запроса. Отменяет строку decisions.md:88 «the page buttons of a disabled MPagination stay natively disabled» |
| Q27-А, механика `mirror` | `MIcon mirror` → `ui-icon--mirror`, `:dir(rtl)` без `[dir=rtl]`-фолбэка, свойство `scale: -1 1`, а не `transform` | `scale` складывается с собственным `transform` потребителя (повёрнутый шеврон), а не затирает его; `:dir()` без фолбэка — по modern-web |
| Q27-А, где стоит | Шевроны пагинации (first/prev/next/last) и иконка-разделитель крошек. У крошек удалены токен `divider.rtl` и правило `[dir='rtl'] &` | Свои глифы кита; текстовый разделитель (`/`, `>`) зеркалит bidi сам |
| B8.5, имена | Rail, bar, drawer — без дефолта и без предупреждения (одиночный landmark / диалог, названный шапкой или `aria-label` потребителя). Крошки — без дефолта, но с dev-предупреждением (`useButtonNameWarning`) | Крошки почти всегда стоят рядом с основной навигацией: второй безымянный `nav` неотличим (axe `landmark-unique`) |
| Reduced motion у drawer | Блок `transition-duration: 0s` удалён: под `prefers-reduced-motion` глобальные токены сжимают `medium-4` до `short-2`, выход `short-4` остаётся. Панель и поверхность — одна длительность | Правило кита «укорачивать, а не убирать»; Vue заканчивает фазу по длительности панели, 0s на ней обрывал слайд мгновенно |
| RTL развёрнутого рейла | Позиции иконки и подписи в развёрнутом виде — через `left: calc(100% - x)` и `translate(-100%)` под `:dir(rtl)`; смещения — ключи `item.expanded.*` карты токенов | Раскрытие анимирует одно свойство без скачка; пункт всё равно заменяет общий фрагмент в P3 (W59-В) |
| Бейджи rail/bar | `inset-inline-end` / `inset-block-start`, ключ `badge.end` вместо `badge.right` | Бейдж стоит у конца иконки в направлении письма |
| Рейл в main `full-height` | Новый флаг хоста `hostIsScroller` в `useLayoutItem` → модификатор `ui-navigation-rail--in-scroller`: `top: 0`, высота `100dvh − inset-top − inset-bottom` | Прокручивается сам main и уже стоит между прибитыми зонами; флаг из provide/inject — класс есть в SSR-HTML |
| e2e `app.e2e.ts:143` | Не баг кита: закрытая панель видна, пока идёт её выход, и следующий владелец открывался рядом. Тест ждёт ухода закрытой панели и ищет панель по имени владельца | Строгий локатор ловил две панели ~100 мс; после выхода закрытая панель из дерева доступности уходит (это тест и проверяет) |
| B1.7a, layout | `carve`, `css`, `registry`, `scroll`, `zone` → `utils/layout/` (не автоимпорт). `useLayout.ts` реэкспортирует типы `LayoutKind`, `LayoutItem`, `LayoutZone` | Прецедент 0.6.0 (`useButton`); типы нужны потребителю `useLayoutZone()` и `m-layout-item kind` |
| `<m-main>` | Удалён без алиаса | Правило «без шимов до стабильной» |
| Safe-area боковых зон | Первая зона каждой стороны (прибитая или нет) берёт вырез своего логического края: прозрачная `border-inline-start/end`, трек `size + inset`, вырез входит в `--m3-layout-inset-inline-*` и смещения баров после неё. `env()` знает только left/right, поэтому layout объявляет `--m3-layout-safe-inline-start/end` на `#id` и `html` с обменом под `:dir(rtl)` | Колонка боковой зоны идёт по всей высоте края окна; логические переменные — одна пара правил вместо дублирования грида под RTL |
| Шаг 8, алиасы классов окна | Вариант А (оркестратор по рекомендации): `is.compact/medium/expanded/large/extraLarge` поверх диапазонов `m-layout` (`tablet-xs`, `desktop-xs`, `desktop`); `medium` = `expanded`. Тип `WindowClassFlags` в `utils/viewport/windowClass.ts`, `shared/types/props.ts` не тронут | Границы M3 (600) разошлись бы с зонами layout: рейл, выбранный по классу, исчез бы на 600–767 |
| Шаг 10, `container` у `m-container` | Корень — size-контейнер `m-container / inline-size`, сетка с полями и пропами колонок — на внутреннем `m-container__grid`. `m-col` узнаёт режим из контекста `m3:grid` и ставит свой набор классов `m-col--cq-<bp>-span/offset-*` под `@container`. Без пропа разметка прежняя. `max-width` по-прежнему от окна | Элемент не может запросить свою ширину; media-правило нельзя «выключить» предком, поэтому у колонки отдельные классы |
| B4.9b (для G2) | `<LiveRegion />` — первый прямой ребёнок `#ui-overlay-host` | Регион в документе до первого сообщения и там же, куда телепортируются поверхности |

## P3 (W53–W70 по рекомендации)

| Пункт | Решение | Причина |
|---|---|---|
| W59-В, общий пункт | `components/fragments/navigation-item/` рисует пункты bar, rail и drawer (модификатор хоста `--bar/--rail/--drawer`); публичный `m-navigation-rail-item` удалён без алиаса; модель выбора — `utils/navigation/useNavigationModel.ts` (вне автоимпорта) | Одна реализация состояний на семейство; внешних потребителей rail-item не было |
| Разметка пункта | `iconPlacement="top"`: подпись под таблеткой; `start`: подпись внутри таблетки | Без замеров, первый кадр SSR верен |
| Таблетка бара | Оставлена 64×32 (план предлагал 56×32) | B5.3a уже одобрен владельцем и закреплён e2e |
| Контейнер рейла | `surface-container` (план — `surface`) | Q22-А прямо называет `surface-container` |
| W56-А | Roving и стрелки убраны у bar и rail: каждый пункт — Tab-стоп | Landmark `nav`, не составной виджет (A11-08) |
| W57-А | `iconPlacement: 'top' \| 'start'` у бара; у `start` боковые поля Centered 20/15/10/5 % по числу пунктов (меньше 3 — как 3, больше 6 — как 6) | Формула Compose из плана |
| W58-А | `disabled` у пунктов bar, rail, drawer — нативный | Пункт — кнопка; вне roving фокус-ловушки нет |
| Бейдж пункта | `aria-hidden`; смысл — `badgeLabel` через `aria-describedby` (скрытый span внутри кнопки); `badge: true` — точка; позиция — миксин G2 `badge-anchor` | Число не попадает в имя пункта (A11-04) |
| W60-Б | Слот `#header="{ expanded, toggleAttrs }"` + `v-model:expanded`; ключи бэга `'aria-expanded'`, `'aria-controls'`, `onClick`; `aria-controls` — id списка в `standard`, id диалога в `modal`/`dismissible` | Текста в ките нет, контракт бэгов как в `behavior.md` |
| W63-А | `mode: standard \| modal \| dismissible` на `MOverlay`; в `modal` свёрнутый рейл остаётся в сетке (зона = свёрнутая ширина), в `dismissible` зона `0rem`; закрывать после выбора — дело приложения (`@select`) | Контент не прыгает (как ModalWideNavigationRail); автозакрытие — UX-предложение, не одобрено |
| Подпись рейла | Проявляется прозрачностью только после первого переключения (`fadeLabel`) | Иначе подписи мигали бы при загрузке |
| W61-А / W62-В, drawer | `items`, `v-model:current`, событие `select`; секции — поле `section` у пункта (заголовок `title-small`, `MDivider`, группа `role="group"`); токены `surface-container-low`, поля 12, ширина 360 / мин 240 / макс 100% − 56; `defineEmits<MOverlayEmits>` | `v-model` drawer уже занят открытием, `current` совпадает с `aria-current`; публичного подкомпонента секции нет (W59-В) |
| W70-А / W69-Б | Активный пункт навигации рисует `filled`-пару глифа; `activeIcon` — ручная замена для глифа без пары. Toggle-кнопки (G6) не тронуты | Без новых зависимостей |
| W53-А | Ось `hierarchy: 'primary' \| 'secondary'` (новое слово — в `axes.md`); модификатор на каждой вкладке через контекст | Селектор от корня задел бы вложенные вкладки |
| W54-А | `layout: 'fixed' \| 'scrollable'`, дефолт `fixed`; вкладки не сжимаются ниже содержимого, не помещаются — ряд прокручивается (скрытая полоса); активная видна с первого кадра через `scroll-initial-target` | Подпись не режется, ряд не распирает родителя; JS-прокрутка после гидратации нарушила бы правило SSR |
| W55-А | При `to` (в `items` или у слотовых `MTab`) — `<nav>` со ссылками и `aria-current="page"` по маршруту, без tablist/панелей/стрелок; v-model не пишется | Обнаружение в рендере `MTabs`, чтобы `<nav>` был в серверном HTML |
| Индикатор вкладок | Один индикатор на ряд через CSS anchor positioning под `@supports (position-anchor: --a)` с `anchor-scope`; без поддержки — индикатор на вкладке. Анимируется `inset-inline` на токенах | Без JS-замеров; `position-area` не анимируется |
| Отключённая вкладка | `aria-disabled` вместо нативного `disabled`, вид — ролями без `opacity` | IN-08, фокус не теряется |
| W65-В | `scrollBehavior: pinned \| collapse` у MAppBar: `animation-timeline: scroll(nearest block)` основным путём, JS-класс `ui-app-bar--collapsed` по `windowY` под `@supports not`; зона `full-height` layout не сворачивается; бар-зона в page-scroll — только CSS-путь | Первый кадр SSR верен; строка зоны вырезана по развёрнутой высоте, ID-правило layout держит `min-block-size` |
| App bar `tag` | `header \| div \| section`, дефолт `header`, внутри зоны `kind=top` — `div` | `header` не вкладывается в `m-layout-header` |
| Высоты medium/large | Верхняя строка = `--ui-app-bar-height-small`, отступ под заголовком 12 → ровно 112 / 120 | Бары были выше токенов зоны (128/120) |
| Перенос заголовка | До 2 строк у medium/large, только вне прибитых зон и не при `collapse` | Строка зоны резервирует одну высоту без замера |
| W66-Б | Ось toolbar `scheme: 'standard' \| 'vibrant'` (новое слово — в `axes.md`) | vibrant меняет роль цвета |
| Toolbar `type` | `floating \| docked` без алиасов, дефолт `floating` (Конфликт №3) | Потребителей с явным `type` в ките нет |
| W67-А | `maxVisible` → меню «⋮» (`fragments/toolbar/overflow.vue`, menuitem/radio/checkbox с `aria-checked`), `moreLabel` без дефолта + dev-warn; без `maxVisible` ряд прокручивается | Без замеров |
| Toolbar safe-area docked | Не делается | Вырез уже отдаёт зона layout — был бы двойной отступ |
| Вес текущей страницы/крошки | 700 (план — 500); ширина кнопки страницы держится скрытой жирной копией номера (`aria-hidden`) в той же grid-ячейке | `label-large` уже 500; `attr()` в контенте попал бы в имя |
| Мишень 48 | `touch-target` (S8 от G1) у кнопок страниц и ссылок крошек (только по блочной оси); на `(pointer: coarse)` ряды раздвигаются ровно до 48 | Мишени соседей смыкаются, не перекрываются |
| Крошки, scroll | Внутренний отступ под кольцо фокуса 5rem (по блоку компенсирован отрицательным `margin-block`), затухание краёв — `mask-position` по `animation-timeline: scroll(self inline)` под `@supports` | Без JS и `--ui-*`; без поддержки края не затухают |
| W68-А | Крошки не обрезаются: только `wrap` (длинное слово переносится) или `scroll` | Решение «без потерь» |
| Фокус пагинации | Если сфокусированная кнопка страницы ушла из окна (уменьшился `length`), фокус — на текущую страницу; только когда он упал на `body` | Фокус не теряется |
| Тултип у обрезанного заголовка app bar (CT-02) | Для любого заголовка в одну строку (small; medium/large в прибитой зоне или при `collapse`): `MTooltip` внутри героя-заголовка с полным текстом, `placement="bottom"`, включён только когда текст обрезан. Обрезку читает `useTitleTruncation` (`ResizeObserver` после mount + смена текста). Корень тултипа — `display: contents` (составной селектор), многоточие несёт `ui-app-bar__text` | Замер только включает тултип и не меняет вид — SSR-кадр тот же. Внутри заголовка обёртки — фразовая разметка (span > h1 был бы невалиден), имя заголовка — его текст, `aria-describedby` не появляется (в заголовке нечего фокусировать, показ — по наведению). Двухстрочный заголовок (`--wrap`) без тултипа: line-clamp на вложенных обёртках не работает |
