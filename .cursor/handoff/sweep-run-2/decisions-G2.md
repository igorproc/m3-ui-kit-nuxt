# Sweep run 2 — решения G2 (оверлеи и feedback)

Принято по рекомендации там, где развилка не покрыта `kit-bugs/questions.md` / W-ответами. Оркестратор переносит в
`docs/system/{en-US,ru-RU}/decisions.md`.

| Q17-А (результат MDialog/MSheet) | `MOverlay` получил событие `dismiss(reason)` (`outside` / `escape` / `swipe`) до закрытия. MDialog/MSheet отвечают `cancel(reason)` на пользовательское закрытие слоя и на `cancel()` слота (`reason: 'cancel'`), `confirm(payload)` из слота; `close()` слота и закрытие родителем через `v-model` — без ответа. Один ответ на открытие (`useModalResult`). | Контракт `useModal` различает cancel (`false`) и «просто закрыли» (`null`); причина нужна W41-Б. Свайп листа — тоже причина (`swipe`), в списке плана modals её не было. |
| Q17 / useModal | Компонент-слот в `useModal({ slots })` получает scope слота пропсами (`confirm`, `cancel`, `close`). | Иначе `#actions` программного диалога не может ответить. |
| B4.6 | Ловушка фокуса по умолчанию фокусирует сам контейнер (`tabindex=-1`), а не первый контрол; MOverlay после неё фокусирует `[autofocus]` контента (B4.5b). | Enter не должен попадать на «Удалить», которое ещё не прочитано; контент сам говорит, что достойно фокуса. |
