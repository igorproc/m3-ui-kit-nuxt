# Sweep run 2 · G6 — решения для переноса в `docs/system/{en-US,ru-RU}/decisions.md`

| Пункт | Решение | Причина |
|---|---|---|
| B13.2a | `plain` входит в `MVariant`; у MButton свой `MButtonVariant = Extract<MVariant, 'elevated' \| 'filled' \| 'tonal' \| 'outlined' \| 'text'>` вместо общего `makeVariantProps` | иначе `plain` попал бы в API кнопок; `MSurfaceVariant` → `Extract<>` делает G5 |
| Q11-А (часть G6) | `MSize`, `SizeProps`, `makeSizeProps` удалены без алиаса; публично реэкспортируется `MLoadingDensity`, а не `MLoadingSize`. Строка `decisions.md:105` («retire `MSize`») закрыта | у типов не было потребителей; OQ-1 решён |
| Q40-Б + S8 | Мишень 48 есть только на грубом указателе (`@media (pointer: coarse)`, общий миксин `touch-target` от G1). Compact MButton и все MButtonIcon переведены на него. Compact FAB и compact extended FAB получили мишень (B8.2a), для этого с корней FAB снят `overflow: hidden`. У icon-only кнопки в MButtonGroup мишень растёт только по блочной оси | modern-web (accessibility §Touch targets): на мыши соседи не должны перехватывать клик. Это меняет прежнее поведение: раньше мишень 48 была у любого указателя |
| B8.3b (расширено) | Ссылка (`tag="link"`) никогда не toggle: не эмитит `update:selected`, не получает `--selected/--unselected`, нет `aria-pressed` (как и раньше) | корень бага: состояние, которое ссылка не может объявить, не должно рисоваться и эмититься. Рекомендация была уже: только `toggle()` early-return |
| N.4 | `.ui-segmented-button { overflow-wrap: normal }` | после фикса G5 карточка и список ломать перестали, но ячейка таблицы и пункт timeline всё ещё задают `anywhere` |
| B8.1 | Резерв цвета контейнера (`--current`) не действует на выбранную text-кнопку: `:where(:not(.ui-button--selected))`, специфичность прежняя | выбранная standard icon-кнопка носит роль (primary) |
| Q1-Б | Для `system` `<html>` оставляет `data-definition="system"`. У каждой палитры (сгенерированной и статической `_m3-fallback`) светлый блок общий с `system`, тёмный продублирован под `@media (prefers-color-scheme: dark)` | первая отрисовка верна без JS, проверено пробой с выключенным JS (light/dark). Цена — +1 блок палитры в CSS |
| Q3-А | Контраст: cookie, затем `contrast` активной палитры, затем `theme.default.contrast`, затем `standard`. Cookie контраста без дефолта (`null` = «не выбран») | доки обещали per-theme contrast |
| Q4-Б | `theme.default.variant` / `neutralChroma` удалены из типов и доков | то же задаётся у темы |
| Q5-А | `semanticColors` мерджится поверх встроенных `success/warning/info`, `false` убирает сид (глобально и у темы) | слово «Extra» в доках и мердж у темы |
| B2.4a | Палитра, которую нельзя отрисовать (необъявленный ключ или кастомный сид не-HEX), всегда откатывается на `theme.default.palette`, и под замком, и без него. `setCustomColor` игнорирует не-HEX | иначе страница остаётся без единого цветового токена |
| B2.4b | Не-HEX `themes[].color` останавливает сборку (`findInvalidSeeds`) | ошибка видна сразу, а не тихое «нет палитры» в рантайме |
| B1.6d | `bp-tablet` = `min-width: tablet-xs` (768), `bp-desktop` = `min-width: desktop-xs` (1200) | так начинаются полосы в `useBreakpoint` и layout |
| B1.2b / Q54 / Q55 | Один пол для Nuxt: `^4.4.8` (peer, `compatibility`, README). `vue` — `^3.5.35`. `sass` — peer `^1.80.0` | пол Nuxt = протестированная версия, `>=4.0.0` не проверялся. Пол sass — допущение: кит использует только модульный API, без функций новее 1.80 |
| ArrowDown FAB-меню (вне списка) | Открытие drawer идёт в post-flush watcher, в том же flush, что монтирует его | в Chromium `[popover]` до `showPopover()` — `display: none`, и фокус на верхний пункт не ставился |
| W52-А, MColor расширен ролями темы | `MColor = 'primary' \| 'secondary' \| 'tertiary' \| 'error' \| 'info' \| 'success' \| 'warning'`; новый общий `MAccentColor = Extract<MColor, 'primary' \| 'secondary' \| 'tertiary' \| 'error'>`. На него сужены `makeColorProps` (кнопки, FAB, группа, segmented, split, fab-menu), `MButtonIcon`, `MRating`, `MTimelineItem` и фрагмент маркера timeline, а также контракт `ColorProps`. Вид не меняется | alert делает `color` осью роли (Q12 «alert — роль»); остальные компоненты сужают ось через `Extract`, как требует axes.md |
