# Showcase — брифы прогона (2026-10-20)

Эксперимент: на ките Vuance UI (`@pr0s1k/primetime-kit`, HEAD `64fb4dc`) собрать 5 приложений и понять,
можно ли уже строить красивые адаптивные продукты, насколько это удобно и каких кирпичиков не хватает.
Главный результат — `FINDINGS.md` каждого приложения и сводный отчёт `report.md` (здесь же, в конце прогона).

## Решения владельца (2026-10-20)

- Приложения: почта, магазин + checkout, таск-менеджер, финансы (сложные) + «умный дом» (простое).
- Живут в `D:\dev\primetime\ui\showcase` (без git), кит подключён из `../kit/src/module.ts`; установка
  зависимостей разрешена (nuxt, vue, sass, @nuxt/icon, @iconify-json/ic, vue-tsc, typescript).
- Кит read-only: баги — обход в приложении + находка.
- Команда: менеджер (Opus) + 3 воркера (Opus) + 1 QA (Haiku). Браузер, dev-серверы и Playwright — только у QA;
  максимум 2 QA-заявки на приложение, в основном когда экран готов.
- Бюджет всего прогона — не больше 1.5 пятичасовых окна.

## Как пересобрать `kit-context.md`

Скрипты лежали в scratchpad сессии: `dump-api.ts` (через `docs_v3/kit-docs/extract.ts`, запуск `jiti` из docs_v3) →
`compact-api.mjs` → `assemble.mjs` + рукописные части. При обновлении кита проще перегенерировать §6 тем же
экстрактором и вручную сверить §7/§13.
