## Изменения

| Что | Сейчас | Цель |
|---|---|---|
| Семантика | `div` | `ul` / `li` с именем «Очередь загрузки» |
| Пусто | «No files selected» | проп без английского дефолта или ничего (CT-13) |
| Добавление и удаление | скачком (MO-01) | `TransitionGroup` на токенах движения |
| Длинная очередь | всё сразу (CT-08) | сводка родителя (предложение UX) или ограниченная высота с прокруткой |
