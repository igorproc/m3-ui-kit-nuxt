## Вердикт

**Авторский.** Группа — чистая раскладка: глобальные индексы ячеек сохраняются (каретка 5 —
позиция 5, а не «вторая в группе»), модели, каретки и завершения у неё нет. Группировка, которая
не сходится с `length`, откатывается в одну группу целиком, а не честится частично. Единственный
дефект — раскладка в grid/flex-родителе (LY-07).

## Поведение и доступность

- Группа `aria-hidden` вместе с ячейками не помечается отдельно: обёртка без роли, внутри только
  скрытые ячейки; повторных «группа 1» нет.
- Порядок DOM = порядок модели; ряд `direction: ltr` в любой локали.
- Слот `#group` получает `complete` — это не визуальное состояние «код готов» (его нет по решению),
  а данные для потребителя.
- **LY-07.** Группы не сжимаются, когда корень — grid- или flex-элемент: `min-width: auto` корня
  держит всю строку. Починка — у корня (шаг 1 [index.md](index.md#план-работ)), у группы
  `min-width: 0` уже есть.
