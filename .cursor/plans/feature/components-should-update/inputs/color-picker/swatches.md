## Поведение и доступность

- **Выбор.** Образец выбран, если его цвет равен цвету модели после нормализации:
  `#6750a4` = `#6750A4` = `rgb(103 80 164)` (ST-01).
- **Клавиатура.** Один Tab-стоп, стрелки, Home/End, Enter и пробел выбирают (A11-08, CT-08).
  Контроллер — общий roving кита (вопрос ВГ-3 из
  [selection-group](../../form/selection-group.md)), третий не заводим.
- **Ключ.** Индекс + значение: дубли значений не ломают рендер.
- **Forced colors.** Выбранный — `Highlight`-рамка (TH-04).

## Тесты

Выбор по нормализованному цвету, стрелки, один Tab-стоп, дубли значений, forced colors.

Выбранный образец виден и объявляется при любом формате, ряд проходится стрелками.
