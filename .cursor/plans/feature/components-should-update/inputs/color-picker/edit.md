## Поведение и доступность

- Невалидный ввод не откатывается молча. Показывается сообщение «Используйте #RRGGBB, rgb() или
  hsl()» (текст — проп). Откат — по Escape, и `parseError` при этом сбрасывается (FM-02, FM-03).
- Подписи «Color value», «R», «G», «B», «A», «H», «S %», «L %» — из пропов родителя без
  английских дефолтов (CT-13).

## Тесты

Ошибка показывает сообщение; Escape откатывает и снимает ошибку; группа каналов с именем.

## Готово, когда
