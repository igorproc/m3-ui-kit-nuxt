<implementation-status state="planned" updated="2026-10-07">Реализован в фазе 2 vuetify-run: один реактивный HSVA-контекст, строковая модель в выбранном формате, приватные части читают и меняют только контекст, `formats` и `swatches`, флаги `hide*`. Открыты: выбранный образец сравнивается строкой, нет видимого фокуса у ползунков, образцы — не listbox с клавиатуры, переключатель форматов сжимается до вертикальных букв, английские строки, нет readonly.</implementation-status>

## Вердикт

`авторский`. Архитектура прежнего плана остаётся:
- HSVA-контекст;
- модель в формате;
- прозрачность определяется форматом, а не флагом;
- смена формата с предупреждением о потере данных;
- части без собственной модели.

Системные дефекты:
- **переключатель форматов** из шести сегментов в ширине 248 ломает подписи на вертикальные
  буквы (рендер). Это следствие решения фазы D о переносе длинных подписей segmented;
- **выбранный образец не находится**, если строка модели отличается регистром или форматом
  (ST-01, `#6750a4` ≠ `#6750A4` на рендере);
- у ползунков hue и alpha отключён `outline` без замены — фокуса не видно (IN-03);
- образцы — `listbox` без стрелок и roving: 100 образцов — 100 Tab-стопов (A11-08, CT-08);
- `role="slider"` на холсте без `aria-valuenow/min/max`; alpha озвучивается как «0.37» (A11-06);
- disabled — общая `opacity` с двойным затемнением вложенных полей (ST-06);
- нет readonly (IN-09);
- ошибка ввода только цветом и молча откатывается (FM-02, FM-03).

| Ось | Нужно | Есть | Не хватает |

| Выбор | образец, равный цвету модели | сравнение строк | сравнение по значению цвета (ST-01) |
| Валидация | ввод с объяснением формата | цвет рамки, тихий откат | сообщение в строке поддержки (FM-02, FM-03) |
| Взаимодействие | pressed у образца, без залипания hover | hover без `can-hover`, увеличение без reduced motion | — (IN-01 закрыт глобально), pressed, `scale` под reduced motion (IN-07, A11-18) |

## Токены: расхождения

| Часть | Система | Кит сейчас (`color-picker/_index.scss`) | Действие |
|---|---|---|---|
| Тени | `elevation(n)` | сырые цвета теней (TK-01) | `elevation()` |
| `white` / `black` | структурные для HSV | литералы | оставить с комментарием «почему»: это математика холста, а не тема |
| Размеры | `spacing()`, ручки по токенам слайдера | литералы, ручки 14–16 (TK-02, RS-06) | `spacing()`, высота ручки как у `MSlider` |
| Фокус | `focus-ring` | только у холста (TK-06) | общий миксин |

## Поведение и доступность

- Группа контролов — `role="group"` с именем (FM-07). Каналы R/G/B/A — вложенная группа.
- Строки «Hue», «Alpha», «Color value», «Saturation and brightness», «R/G/B/A» — из пропов
  или констант сообщений без английских дефолтов (CT-13, Q13).
- Ползунки — `aria-valuetext` («Оттенок 258°», «Прозрачность 92%»). RTL-градиенты по
  логическому направлению (LY-10).
- Слушатели `window` у холста — только на время перетаскивания (EN-10).

## План работ

1. **S — сравнение образцов по значению цвета** (ST-01).
2. **S — фокус ползунков и образцов, токены фокуса** (IN-03, IN-04, TK-06).
3. **M — образцы как listbox с roving и стрелками** (A11-08, CT-08), ключ по индексу + значению.
4. **S — ARIA холста и ползунков** (A11-06), **группа** (FM-07).
5. **S — переключатель форматов** — по вопросу 1.
6. **S — ошибка с объяснением формата, сброс `parseError` при откате** (FM-02, FM-03).
7. **S — disabled по ролям и readonly** (ST-06, IN-09).
8. **S — токены, тени, RTL-градиенты, reduced motion** (TK-01, TK-02, LY-04, LY-10, A11-18).
9. **S — слушатели только на время драга** (EN-10).
10. **M — тесты и документация** (TS-07, DC-*).

## Тесты

- Unit:
  - образец `#6750A4` выбран при модели `#6750a4` и `rgb(103, 80, 164)`;
  - стрелки по образцам;
  - клавиатура холста;
  - невалидный hex показывает сообщение и сбрасывает ошибку при откате;
  - readonly не меняет модель.
- e2e:
  - видимый фокус у hue;
  - формат на 248 не ломает подписи;
  - RTL-градиент;
  - axe.

## Готово, когда

- Выбор образца стабилен при любом формате.
- Каждая часть видимо фокусируется и проходится с клавиатуры.
- Ошибка объясняется.
- Переключатель форматов читаем на любой ширине.

## Открытые вопросы

**1. Как показывать переключатель форматов в узком пикере?** Сейчас шесть сегментов в 248
ломаются на вертикальные буквы.
1. Компактный выпадающий список `MDropdown density="compact"` рядом с полем значения. Всегда
   помещается, но формат виден, только когда открыт список.
2. Оставить segmented, но показывать только семейства (HEX · RGB · HSL), а прозрачность —
   отдельным тумблером «альфа». Три сегмента помещаются, но меняется модель форматов,
   утверждённая в прежнем плане.
3. Segmented с прокруткой по горизонтали. Без смены модели, но шесть сегментов в 248 всё равно
   неудобны.

Рекомендация: 1. Модель форматов не меняется, вид — минимальное изменение.
