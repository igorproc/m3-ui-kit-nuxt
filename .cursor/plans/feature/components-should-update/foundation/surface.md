## Вердикт

`авторский`. Это примитив кита, а не компонент M3. Его четыре пресета и узкий API (`tag`,
`variant`, `shape`) — решение владельца, они остаются. Расхождения только системные:
- карта токенов читается легаси-путями через дефис;
- шкала форм не знает ступеней Expressive (S2);
- обводка задана как `1rem`, а при vw-корне это не всегда hairline.

## Поведение и доступность

- Корень по умолчанию — нейтральный `div` без роли. Семантику (`section`, `aside`, `article`)
  выбирает потребитель. Порядок чтения и фокуса компонент не меняет.
- Интерактивности нет и не будет: `interactive`, `disabled`, `selected`, ripple, `role`,
  `tabindex`, событие `click` отсутствуют. `@click` через fallthrough — ответственность
  потребителя, для интерактивного контейнера есть `MCard`, `MListItem`, `MButton`.
- Аудит:
  - TK-01 (сырая тень) закрыт переходом на `elevation(1)`;
  - TH-04 закрыт;
  - TK-02 (ширина обводки) остаётся, см. вопрос 2.

## API

Без изменений. Публичный API ограничен `tag`, `variant`, `shape`. `level`, `elevation`,
`color`, `rounded`, `interactive` по-прежнему отсутствуют — это решение владельца.

Потребители внутри кита: `MAlert`, `MBanner`, `MTimelineItem`. Любое изменение пресетов меняет и их.

## План работ

1. **S — точечные пути.** `index.vue`: все `g()` перевести на точки. Проверить собранный CSS:
   каждое правило пресета на месте.
2. **S — hairline.** По ответу на вопрос 2: `outline.width` → общий токен hairline, если он
   появится в системе.
3. **S — `MSurfaceVariant` через `Extract<>`.** Делается вместе с миграцией «`plain` входит в
   `MVariant`» из `decisions.md`, отдельно не начинать.
4. **S — документация границ.** Таблица выбора контейнера в docs:
   - собственная область → MSurface;
   - структурированный контент с действием → MCard;
   - ширина страницы → MContainer/MLayout;
   - модальное снизу → MSheet;
   - плавающее → MMenu/MOverlay.

## Открытые вопросы

**1. Добавлять ли ось `tone` (lowest · low · default · high · highest)?**
1. Нет. API остаётся `tag`/`variant`/`shape`, как решено при создании. Ничего не ломается, но
   потребитель, которому нужен `surface-container-high`, по-прежнему собирает его вручную.
2. Да, как необязательный проп `tone` поверх `filled`. Покрывает всю лестницу M3, но нарушает
   прежнее «ни цвета, ни уровня» и даёт второй способ выбрать тон.

Рекомендация: 1, пока не появится названный заказчик (принцип В4).

**2. Ширина обводки при vw-корне.**
1. Оставить `1rem`: обводка масштабируется вместе с макетом, на 1920 это ровно 1px. На узких
   окнах линия тоньше пикселя и может выглядеть бледнее.
2. Ввести системный токен hairline, равный `1px`, для всех `outlined`-контейнеров кита. Всегда
   ровно один пиксель, но это первое физическое значение в шкале на rem.

Рекомендация: 2, одним решением для всех outlined-компонентов (card, surface, chip, поля).
