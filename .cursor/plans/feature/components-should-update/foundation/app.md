## Вердикт

`авторский` (инфраструктура). Подключает инфраструктуру кита одной оболочкой:
- атрибуты темы до первого кадра;
- единственный `#ui-overlay-host`;
- контейнер программных модалок `useModal()`;
- слот `loading`;
- ссылку «Перейти к содержимому», если дан её текст.

От M3 берутся только роли фона, и они совпадают. Решения из прежнего плана остаются:
- компонент необязателен;
- раскладку не строит;
- визуального индикатора загрузки по умолчанию нет;
- второй `MApp` даёт предупреждение.

## Рендеры

Не применимо: собственного вида нет, кроме фона `background`.

## Поведение и доступность

- Ландмарков не создаёт: они принадлежат раскладке и странице.
- За `aria-busy` и озвучку загрузки отвечает потребитель слота; в документации нужен пример.
- `NuxtRouteAnnouncer` и маршрутизация остаются в слоте приложения: `MApp` не добавляет их сам,
  чтобы не было дублей.
- **EN-04, P2.** `defineExpose({ rootElement: rootElement?.value })` отдаёт значение в момент
  setup, а там всегда `null`. Нужно отдавать сам ref: `defineExpose({ rootElement })`.
  Исправлено 2026-10-07.
- Ссылка «Перейти к содержимому» — обычный якорь `href="#<id>"`: нативная навигация по
  фрагменту переносит точку последовательного фокуса к цели, JS не нужен. Скрыта через
  `sr-only`, в фокусе встаёт поверх страницы на `z(overlay-host)`.

## API

- Пропы и публичные типы живут в `props.ts`: `mAppProps` через `propsFactory`, `MAppProps`,
  `MAppSlots`, `MAppLoadingState`, `MAppExposed`.
- `expose`: `rootElement` — `Readonly<ShallowRef<HTMLElement | null>>`. Через ref компонента
  он читается развёрнутым (`app.value.rootElement` — элемент после монтирования). Строго
  говоря, это меняет тип, но прежнее значение было всегда `null`.
- `skipLinkLabel?: string` — текст ссылки; без него ссылки нет, английского дефолта нет.
- `skipLinkTarget: string = 'main'` — id элемента, к которому ведёт ссылка.

## Тесты

- Unit:
  - SSR: один хост;
  - атрибуты темы есть в первом кадре;
  - слот загрузки реагирует на изменения;

- e2e: меню и выпадающий список внутри своего `app.vue` открываются в хосте.

Сделано 2026-10-07: unit проверяет один хост в смонтированном DOM и head-запись темы через
`injectHead().resolveTags()`; настоящий серверный HTML (атрибуты на `<html>`, один хост)
проверяет e2e запросом сырой страницы. Фикстура не может вложить второй `MApp` без побочек
