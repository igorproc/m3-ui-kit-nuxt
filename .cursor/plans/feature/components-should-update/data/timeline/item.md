## Вердикт

`авторский`. Элемент регистрируется в контексте родителя и рисует свою строку: время, рейку с
точкой, содержимое на `MSurface`. Меняются три вещи:
- смысл маркера должен читаться без цвета;
- колонка времени появляется только при наличии времени;
- обещанный в API «акцент содержимого» для outlined не реализован (ST-01) — реализовать
  или убрать.

## Рендеры

Общие с родителем: `renders/timeline`.

## Анатомия

| # | Часть | В ките | Изменение |

| 2 | Точка | `color` (роль), `icon` | при `status` — значок по умолчанию |
| 3 | Содержимое | `MSurface variant`, `title`, `text`, слоты | `overflow-wrap: anywhere` |
| 4 | Скрытый статус | — | новый: визуально скрытый текст статуса |

## Поведение и доступность

- Значок точки декоративен. Смысл несёт скрытый `label` статуса (TH-05).
- `datetime` обязателен в паре с `time`. Без него в dev предупреждение.

## Тесты

`status` даёт значок и скрытый текст; без `time` нет колонки; `datetime` у `<time>`.

## Готово, когда

Статус читается без цвета, колонка времени не пустует.

Нет: расширения — у [родителя](index.md).
