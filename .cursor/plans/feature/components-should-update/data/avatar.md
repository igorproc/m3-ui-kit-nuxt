## Вердикт

`авторский`. Решения прежнего плана остаются:
- пассивная поверхность без интерактивности;
- корень заранее резервирует размер;
- детерминированная цепочка запасных вариантов;
- нет произвольного числового размера мимо шкалы.

Изменения:
- **ось масштаба `size` → `density`** — решение из `decisions.md` с ступенями владельца
  (compact 24 · default 40 · comfortable 56: значения совпадают с текущими sm / md / lg);
- ошибка изображения, случившаяся до гидрации, не обрабатывается (ST-01, CT-09);
- в forced colors outlined теряет обводку, нарисованную `box-shadow`;
- при упавшем изображении имя теряется (A11-05).

## Оси дизайна

| Ось | Значения | Цель | Ломает API |
|---|---|---|---|
| Масштаб | `size: sm \| md \| lg` | `density: compact \| default \| comfortable` (24 / 40 / 56); `size` — алиас с предупреждением | да, через алиас |
| `shape` | `Extract<MShape, 'full' \| 'large' \| 'medium' \| 'small'>` | без изменений | — |
| `variant` | `tonal \| filled \| outlined` | самостоятельный юнион → `Extract<MVariant, …>` (`axes.md`) | нет |

## Оси состояний

| Ось | Нужно | Есть | Не хватает |
|---|---|---|---|
| Данные | загружено · ошибка (включая до гидрации) | ошибка после гидрации | проверка `img.complete && naturalWidth === 0` при монтировании (ST-01, CT-09) |
| Доступность | имя при любом варианте | имя только у `<img alt>` | при запасном варианте корень получает `role="img"` и `aria-label` из `alt`/`name` (A11-05) |
| Forced colors | граница видна | нет | `border` вместо `box-shadow`; у tonal/filled — `outline` под `forced-colors` |

## Поведение и доступность

- Корень резервирует размер до загрузки, при успехе и ошибке размер не меняется (решение
  прежнего плана).
- Декоративный аватар рядом с видимым именем помечается `alt=""` — документировать рецепт.

## Тесты

- Unit:
  - алиас `size` предупреждает;
  - изображение, упавшее до монтирования (мок `complete` + `naturalWidth`), даёт инициалы;
  - `role="img"` с именем при запасном варианте.
- e2e: forced colors у outlined; axe.

## Готово, когда

- Ось называется `density`.
- Ошибка изображения обрабатывается всегда.
- Имя не теряется.
- Обводка видна в forced colors.
