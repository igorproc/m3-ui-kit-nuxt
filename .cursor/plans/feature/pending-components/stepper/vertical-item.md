## Вердикт

`нет в ките`. Вертикальный шаг соединяет заголовок со статусом, рейку и условно смонтированное
тело. Навигацией не владеет (прежнее решение).

## Рендеры

Общие с родителем: `renders/stepper/concept.webp`, кадр 5.

| # | Часть | Реализация |
|---|---|---|
| 1 | Заголовок | правила статуса и вид [StepperItem](item.md); во всю ширину, как строка списка, высота 56 / 72 по числу строк |
| 2 | Тело | монтируется по состоянию, выведенному из `WindowItem`; отступ 52 |
| 3 | Локальные действия | [StepperVerticalActions](vertical-actions.md), только у активного тела |

## Оси состояний

Статус и взаимодействие — как у [StepperItem](item.md). Тело: активно / сохранено (`hidden` +
`inert`) / не смонтировано.

## Токены

Ветки `header.*`, `indicator.*`, `vertical.body.*` карты родителя.

## Поведение и доступность

- Запрос из заголовка уходит в корень.
- Неактивное сохранённое тело `hidden` и `inert`, фокус в него не попадает. Действия есть только у
  активного тела. Статус не выводится из того, смонтировано ли содержимое (прежнее).
- Пара `id` «заголовок — тело», `aria-current="step"` у текущего; порядок чтения — порядок DOM.
