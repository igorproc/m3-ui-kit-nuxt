## Токены

Нет своих: движение — `MWindow`, отступ — карта родителя.

## Поведение и доступность

- Тонкий адаптер над слотом и состоянием `WindowItem`: второй тикет шага не регистрирует и сам
  навигацию не запрашивает (прежнее).
- Неактивная сохранённая панель `hidden` и `inert`. Программный фокус в панель — только по
  политике корня.

## API

Внутренние: шаг, значение, индекс, `headerId`, `panelId`, слот содержимого. Ни модели, ни эмитов,
ни реестра.
