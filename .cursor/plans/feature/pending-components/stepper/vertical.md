## Вердикт

`нет в ките`. Вертикальный сценарий перемежает заголовок, рейку, тело и локальные действия, в
отличие от горизонтальной пары «ряд заголовков + окно». Рендер не хранит состояние: он рисует тот
же сценарий корня (прежнее решение).

## Токены

Ветка `vertical.*` карты родителя: `vertical.rail.*`, `vertical.body.inset`,
`vertical.body.padding`, `vertical.body.motion` (раскрытие высоты на `medium-2`, как у
`MExpansionPanel`; reduced motion — `short-1`). Логические свойства для RTL.

## Поведение и доступность

- Порядок чтения в DOM: заголовок → тело активного шага → локальные действия → следующий
  заголовок. CSS порядок шагов не меняет (прежнее).
- Видно только активное тело; сохранение тел — по политике `mount` корня (прежнее).
- Раскладка — проп, а не брейкпойнт (прежнее: без двойного DOM).

## API

Внутренние: нормализованные шаги, текущий, `mount`, состояние навигации и проброшенные слоты
метки, панели и действий. Ни модели, ни контекста: прямой ребёнок корня получает пропы напрямую,
контекст корня остаётся единственным источником сценария (прежнее).
