## Вердикт

`нет в ките`, в M3 нет. Нужна компактная столбчатая визуализация ряда чисел без подключения
charting-библиотеки (прежняя задача). Данные и форматирование контролирует потребитель.

Столбики — HTML, а не SVG: flex-колонки с высотой в процентах. Так угол 4 у конца данных не
искажается при любой ширине, и ничего не надо мерить.

## Оси состояний

Общие для лаборатории. Своё: активный столбик выделяется слоем состояния 8%, а не другим
цветом.

## Токены

Карта `chart`, ветка `bar`: `bar.max` 24, `bar.shape` `extra-small`, `bar.gap` 2. Прежняя
отдельная карта `components/barline/_index.scss` не нужна.

## Поведение и доступность

Общие для лаборатории:
- одна остановка Tab, ←/→ по столбикам;
- статус «подпись: значение»;
- скрытая таблица;
- `role="img"` с осмысленным именем в статичном режиме.

Рисование (`autoDraw`) растит столбики от базы и уважает reduced motion. SSR рендерит финальный
кадр без сдвига раскладки (прежний план).

## API

```ts
interface MBarlineProps extends MChartBaseProps {
  baseline?: 'zero' | 'min'                  // по вопросу 1
  labels?: 'none' | 'last' | 'extremes'      // 'none'
}
```

Слот `label` прежнего плана → слот `tooltip` и подписи `labels`. Событий нет, кроме
`v-model:active`.

## План работ (после продвижения лаборатории)

1. **S — компонент или форма** по вопросу 1 лаборатории.
2. **S — отрицательные значения** и нулевая база.
3. **S — тесты.**

## Тесты

Шкала и min/max; база ноль и min; отрицательные значения; угол только у конца данных; зазор;
SSR-кадр; reduced motion; имя (прежний набор) + клавиатура и таблица значений.

## Готово, когда

Барлайн читаем, токенизирован, не вызывает сдвига раскладки (прежнее условие) и не держит своей
копии шкалы — она общая со спарклайном.

## Открытые вопросы

**1. Базовая линия по умолчанию (вопрос прежнего плана).**
1. От нуля. Длина столбика честно кодирует величину; отрицательные растут вниз.
2. От минимума ряда. Мелкие колебания видны крупнее, но столбик в 2 раза выше не значит «в 2
   раза больше» — это искажение.

Рекомендация: 1; `min` — по явному пропу.
