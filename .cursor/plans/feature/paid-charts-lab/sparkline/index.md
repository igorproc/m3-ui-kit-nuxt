## Вердикт

`нет в ките`, в M3 нет. Компактная линия тренда числового ряда. Активная точка показывается
по наведению и с клавиатуры, значение — тултипом и постоянным статусом. Форматирование данных
остаётся у потребителя (прежний план).

От Vuetify уходит:
- `model` → `data` только для чтения: график не редактирует вход;
- `gradient` из произвольных цветов → роль `color`;
- событие `hover(index)` → `v-model:active`.

## Оси состояний

Общие для лаборатории ([index](../index.md)): rest, hover, focus, активная точка, данные (пусто,
одна точка, константа, разрыв, вне диапазона), reduced motion, forced colors.

## Токены

Карта `chart` лаборатории, своих веток нет. Отличается только дефолт: `endMarker` включён.

## Поведение и доступность

- Корень интерактивного режима — `role="group"` с именем и одной остановкой Tab. ←/→, Home и End
  ходят по точкам, Esc снимает активную.
- Указатель выбирает ближайшую точку по X. Цель — вся ширина шага, не меньше 24.
- Статус объявляет «подпись: значение» через `format`. Тултип `aria-hidden`.
- Скрытая таблица значений — текстовая альтернатива.
- SSR — финальный путь в HTML. `autoDraw` — только по желанию и не под reduced motion.

## API

```ts
interface MSparklineProps extends MChartBaseProps {   // общая часть — index лаборатории
  smooth?: boolean        // false — linear
  fill?: boolean          // false
  endMarker?: boolean     // true
  labels?: 'none' | 'last' | 'extremes'   // 'none'
}
const active = defineModel<number | null>('active', { default: null })
```

Слоты: `tooltip` (`{ datum, index }`) — содержимое тултипа. События: нет, кроме модели `active`.

## План работ (после продвижения лаборатории)

1. **S — компонент** над общей геометрией и `useChartControl` (шаги 1–2 лаборатории).
2. **S — подписи `labels`**: последнее значение и экстремумы без пересечений с маркером.
3. **S — тултип** ([tooltip.md](tooltip.md)).
4. **S — тесты.**

## Тесты

Путь `linear` и `smooth` (монотонность: путь не выходит за min/max); `fill`; активная точка от
клавиатуры и указателя; `v-model:active`; разрыв на `null`; SSR-кадр; reduced motion; axe; имя или
декоративный режим.

## Готово, когда

Спарклайн синхронизирует путь, точку, статус и тултип из одного источника (прежнее условие) и не
дублирует математику общей геометрии.

## Открытые вопросы

**1. Интерполяция по умолчанию (вопрос прежнего плана).**
1. `linear`. Честно показывает измеренные точки, путь не проходит там, где данных нет.
2. `smooth` (монотонная кубическая). Мягче на вид, без выброса за экстремумы, но рисует
   промежуточные значения, которых не было.

Рекомендация: 1; `smooth` — по флагу.
