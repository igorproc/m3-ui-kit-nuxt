## Вердикт

`нет в ките`, в M3 нет. Нужна визуализация с заполнением под линией: акцент на форме тренда, а
не на отдельных точках (прежняя задача).

Технически это путь спарклайна, замкнутый на базу. Своей математики нет: это прежнее условие
«переиспользует sparkline-геометрию без копии».

## Оси состояний

Общие для лаборатории. Активная точка показывается маркером на линии, площадь не меняется.

## Токены

Карта `chart`: `area.opacity` 10% (или `area.fade.from` / `area.fade.to` по вопросу 1). Прежняя
отдельная карта `components/trendline/_index.scss` не нужна.

## Поведение и доступность

Общие для лаборатории. В статичном режиме имя-сводка описывает направление («рост на 24% за 12
месяцев» — текст потребителя, прежний план). Reduced motion отключает рисование. SSR — финальный
кадр.

## API

```ts
interface MTrendlineProps extends MChartBaseProps {
  smooth?: boolean
  fill?: 'wash' | 'fade'     // по вопросу 1
}
```

## Тесты

Путь площади; заливка; min/max; база; SSR-кадр; reduced motion; имя (прежний набор).

## Готово, когда

Трендлайн переиспользует геометрию спарклайна без копии математики (прежнее условие), а площадь
нарисована одной ролью.

## Открытые вопросы

**1. Заливка площади (вопрос прежнего плана: обязателен ли градиент).**
1. Ровная вуаль роли на 10%. Одна роль, одна непрозрачность, ничего не спорит с линией; так
   рисуют площадь системные правила визуализации.
2. Угасание той же роли сверху вниз (16% → 0%). Красивее, но это второе значение непрозрачности.
   Угасание к базе читается как «значения убывают к нулю», хотя это не так.
3. Градиент из нескольких ролей, как `gradient` Vuetify. Это выбор оттенков, а не назначение роли
   (`principles.md`, В3) — не рекомендуется.

Рекомендация: 1. Градиент необязателен, допустима сплошная вуаль.
