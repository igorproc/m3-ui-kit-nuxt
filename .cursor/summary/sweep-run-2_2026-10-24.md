## Ломающие изменения (в changelog 0.6.0; кит 0.x, без шимов)

Выбор: корни MCheckbox/MSwitch/MRadio — `div`; `loading` снят у checkbox/switch/rating; MRating без имени
по умолчанию; suggestion-чип по умолчанию outlined; MSlider — фрагмент `range` удалён, бэги без `data-*`,
`insetInlineStart`; MFormRenderer — `submitLabel` без дефолта, событие `submitted`.
Оверлеи/feedback: MMenu `absolute` удалён, `origin` → `placement`; `usePopover` стороны `start/end`;
`size` → `density` у MLoading/MProgress (`MSize` и др. удалены); MAlert `type` → `color`; MBanner
`surface` → `plain`; MBadge не live-регион по умолчанию; snackbar без `trapFocus`.
Навигация/layout: `<m-main>`, `m-navigation-rail-item` удалены; внутренности layout и hotkey не
автоимпортируются; без английских имён у rail/bar/drawer/breadcrumbs/pagination.
Поля: `MNumberInputUnit` приватный; без английских дефолтов у number-input/textarea/пикеров; date-picker
`modeToggle` по умолчанию выключен.
Тема/типы: `data-definition="system"`; `MColor` шире (`MAccentColor` для прежних четырёх); мишень 48
только на таче; ссылка-кнопка никогда не toggle; `bp-tablet` → `tablet-xs`.

## Найдено, не чинилось

- Бар внутри `m-layout-main` отдаёт свой размер зоне main; `windowY` не читает начальную прокрутку;
  модификатор подзаголовка составного `MAppBarTitle` не в SSR; отрицательный margin мишени крошек
  перекрывает соседей.
- Модульное состояние: `keyboardRipple` в ripple, `useScrollLock`.
- Логический `position-area` не учитывает RTL-поддерево с другим `dir`.
- В `multiple` пресет модели после монтирования переупорядочивается по регистрации.
- MTextField/MTextarea без dev-предупреждения о безымянности.
- `import.meta.dev` = false в Vitest — dev-предупреждения проверяются только в e2e.
- Вне репо: docs_v3 `.shiki` и копия миксина темы в docs_v2 (`azbuka`) не знают `system`; showcase
  mail/tasks используют `@container main-content` без `container`; docs_v3 описывает удалённые
  `--ui-scrollbar-inset-*`.
