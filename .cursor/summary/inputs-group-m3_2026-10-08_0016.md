# Группа INPUTS: поля, пикеры, загрузка — M3 по планам — 2026-10-08

Предыдущий шаг: [m3-parity-research_2026-10-07_0400.md](m3-parity-research_2026-10-07_0400.md)
(планы `inputs/*`). Параллельно шли группы button, containment, data — их файлы не трогались.

Работа автономная: в каждом открытом вопросе взята рекомендация плана, кроме отмеченных случаев.
Dev-сервер, Playwright и build не запускались — всё, что касается CSS, **в браузере не смотрено**.

## Решения (открытые вопросы планов)

- text-field / 1 → 1: лейбл не движется, float всегда поднят статично. 2 → 2: `type="number"` —
  dev-предупреждение, путь — `MNumberInput`. 3 → 1: `top` = `body-medium`. 4 → 2: счётчика нет
  (запись в decisions.md ниже). 5 → 1: пропы `prefix` / `suffix`. 6 → 2: reveal нет (CT-13).
  7 → 1: `shape` + алиас `rounded` на релиз.
- textarea / 1 → 1: счётчик в строке поддержки. 2 → 1: hover outlined — только кромка.
- number-input / 1 → 1: формы нажатия у зон нет.
- otp-input / 1–3, 6, 7 → 1. 4 → 1 с поправкой сессии: `MLoading` в строке сообщения вместо
  `MProgressLinear` (решение сессии «loading = MLoading»). 5 → 1: без density (decisions.md).
- search / 1 → 2: фокус строки — кольцо кита на корне.
- dropdown / 1 → 1: высота строки = высота поля (decisions.md). 2 → 1: галочка в trailing.
  3 → 2: потолок панели на половине строки.
- autocomplete / 1 → 1: начальное значение — только черновик, без `search`. 2 → 1: `#hint` без
  дефолта. 3 → 1: `clear` в `#no-results`. 4 → 2: `openOnFocus: 'pointer'`. UX: поиск без учёта
  диакритики.
- file-upload / 1 → 1: скрытый picker вместо вложенного поля.
- color-picker / 1 → 1: формат — компактный `MDropdown`. canvas / 1 → 1: две скрытые оси-слайдера.
- date-picker / 1 → 1: встроенный без actions, клик коммитит. 2 → 1: дни соседних месяцев не
  рисуются. 3 → 2: плоская карточка `large` без тени. 4 → 2: без `MDateField`. 5 → 3: range не
  делается. 6 → 1: `Intl` + арифметика dayjs.
- time-picker / 1 → 2: карточка остаётся. 2 → 2: без `MDialogTime`. 3 → 3: `hourCycle`,
  по умолчанию `h23`. 4 → 2: циферблат — один `role="slider"`. 5 → 1: Expressive-пара без морфа.
  6 → 1: явная ось + складывание по container query. 7 → 1: rich и ScrollField не вводятся.
  8 → 1: селекторы-кнопки. 9 → 1: `picker | input`.
- time-picker / 4, отклонение от буквы плана: опция `wrap` в `createRangeKeyboardController` не
  добавлена (файл группы slider). Тот же контроллер переиспользован без правки: значение стоит в
  середине трёх кругов, шаг за край переходит через ноль. PageUp/PageDown — ±10 (как у
  контроллера), а не ±5 из плана.
- time-picker: радиусы колец (101/256, 69/256) — доли в `createClock`, а не CSS-свойство, как
  предлагал план: правило сессии запрещает компонентные custom properties для статичных значений.
- confirm-edit / 1 → 2: компонента нет, поставляется `useConfirmEditTransaction`.

## Проверить глазами

Не смотрено в браузере ничего. Ширины 360 / 768 / 1366, светлая и тёмная, `?dir=rtl`.

- `text-field/matrix`, `textarea/matrix`, `number-input/matrix`: filled 56 по умолчанию, значение
  по вертикали не съехало; лейбл float поднят и не анимируется; outlined inset внутри коробки;
  prefix/suffix в строке значения; hover filled — слой, outlined — кромка; disabled filled —
  индикатор 38%; `shape` full у filled ограничен large.
- `otp-input/matrix`: три варианта, placeholder в пустых ячейках, `mask="last"` показывает
  последний символ ≈1 с, звёздочка required, MLoading в строке сообщения.
- `search/matrix`: контейнер без рамки и тени, 56; кнопка очистки не сдвигает текст; кольцо
  фокуса на всём контейнере; trailing + avatar.
- `dropdown/matrix`, `autocomplete/matrix`: галочка справа у выбранной строки, текст строк на
  одной линии со значением поля; панель обрезает строку пополам.

  посередине с расширением; refusing-вид при перетаскивании неподходящего файла.

## Ломающие изменения и миграция

- Поля (`text-field`, `textarea`, `number-input`, `dropdown`, `autocomplete`, `file-input`,
  `color-input`): `rounded` → `shape` (`none | extra-small | medium | large | full`; алиас на
  релиз с dev-предупреждением); классы `--<rounded>` → `--shape-<shape>`; `--populated` убран;
  у text-field проп `populated` снят (предупреждение).
- text-field: `type="number"` даёт dev-предупреждение → `MNumberInput`.
- number-input (headless): `supportAttrs` без `role`, новый `alertAttrs` (`role="alert"`).
- otp-input: `mask: true` → `'always'`, строка-символ → `'always'` (алиасы на релиз); вид по
  умолчанию — outlined без заливки; класс `--complete` убран.
- search: дефолт `placeholder` снят; «Clear search» → `clearLabel`; классы `__icon--leading` →
  `__leading`, `__icon--trailing` → `__clear`; без `aria-label` — dev-предупреждение.
- dropdown / autocomplete: галочка в trailing; `openOnFocus: boolean | 'pointer'`, дефолт
  `'pointer'` (было `true`) — вернуть: `:open-on-focus="true"`.
- file-input: «Browse», «Clear selected files», «Selected files: N» → `browseLabel`, `clearLabel`.
- file-upload: все строки → `messages` (`MFileUploadMessages`); корень `role="group"`.

  listbox (activedescendant), а не кнопки; `role="slider"` холста перенесён на две скрытые оси.
- color-input: «Open color picker…» → `pickerLabel`.
- date-picker: футер Cancel/OK и события `cancel` / `confirm` сняты — свои кнопки в `#actions`,
  диалог — `MDialogDate`; `headline` → `label` (алиас); дни соседних месяцев не рисуются;
  классы `__headline-label`, `__year-grid`, `--placeholder` убраны; таблицы `_docked`,
  `_modal-picker`, `_modal-input` удалены; первый день недели — из локали.

- time-picker: `is24h` → `hour-cycle` (`'h23'` / `'h12'`, алиас); `mode="dial" | "keyboard"` →

  `mTimePickerDialProps`, `MTimePickerDialProps` удалены; классы `.ui-time-picker-dial*` /
  `.ui-time-picker-keyboard*` → `.ui-time-picker__*`; режим ввода тоже в карточке.
- Внутри кита все потребители поправлены; вне кита — страница docs time-picker (Playground на
  `mode: 'dial' | 'keyboard'` и `is24h`) работает через алиасы с предупреждениями.

## Открытые вопросы для лида

1. **Литерал 4% disabled-контейнера filled (ST-05)** в text-field / number-input. Сессия
   зафиксировала disabled-container = 12%, а M3 для filled-поля даёт 4%.
   1) Ключ `disabled-container-subtle: 4%` в `$theme-state-link` (системная группа). Цена: новый
   системный ключ. 2) Оставить литерал в `$tokens` с комментарием. Цена: исключение из правила.
   3) 12%, как у остальных. Цена: filled disabled заметно темнее M3. Рекомендация: 1.
2. **Футер textarea в disabled (ST-06)**: сейчас `opacity: 0.6`.
   1) Контент футера 38% ролями + `inert`. 2) Оставить. Рекомендация: 1 (S, по ролям системы).
3. **Фокус заполненного OTP-кода**: каретка за последней ячейкой — активной ячейки нет.
   1) Кольцо вокруг всей группы ячеек. 2) Последняя ячейка как активная. 3) Оставить.
   Рекомендация: 1 (craft §8 запрещает подсвечивать ячейку, в которую не пойдёт ввод).
4. **MMenu как поверхность пикеров** (color-input A11-06, search view, dropdown шаг 3): роль
   `menu`, перехват стрелок, возврат фокуса. 1) Примитив поповера с `role="dialog"` из плана
   меню, color-input и search view переезжают на него. 2) Оставить локальную изоляцию клавиш.
   Рекомендация: 1.
5. **form-renderer рендерит `MTextField type="number"`** — теперь это dev-предупреждение.
   1) Группа форм переводит поле на `MNumberInput`. 2) Глушить предупреждение для form-renderer.
   Рекомендация: 1.
6. **Общие константы**: добавлены строки `date*` / `time*` в `MESSAGES`, 10 иконок в `ICONS`,
   `OTP_MASK_REVEAL`. 1) Принять. 2) Перенести строки только в пропы. Рекомендация: 1.
7. **Данные dropdown / autocomplete** (шаг 5 / 7: `loadError`, `#error`, `retry`, задержка
   индикатора) не начаты — новый публичный API. 1) Следующей волной по плану. 2) Ждать
   заказчика. Рекомендация: 1.
8. **Длинная очередь file-upload (CT-08)**. 1) `max-height` списка токеном + прокрутка.
   2) Сводка «N файлов, M с ошибкой» + сворачивание. 3) Оставить. Рекомендация: 1.
9. **`wrap` у `createRangeKeyboardController`**. 1) Оставить приём «три круга» в

10. **Холодный старт vitest** (чистые спеки падают по `hookTimeout` 10 с без прогрева).

### Падения: причина и исправление

- **text-field / textarea / number-input — строка поддержки 16; search — высота 56.**
  Неверное допущение теста: px сравнивались с дизайн-единицами (1rem ≈ 0.667px при 1280).
  Делим на `remInPx(page)`.
- **text-field — float/inset-лейбл «двигается» на фокусе (335 vs 741).** Неверное допущение:
  фокус прокручивает страницу. Положение лейбла меряется относительно поля; лейбл не движется.
- **number-input — filled на дизайн-пиксель выше text-field.** Дефект компонента: рамка 1rem
  (0.667px) рисуется целым пикселем, а контрол рос по содержимому (`min-height`). Теперь
  `height` = высота плотности; значения стоят на тех же 18 / 24 / 28, что у text-field.
- **file-input — лейбл «на» именах файлов.** Неверное допущение: сравнивался верх бокса input
  (он включает паддинг под лейблом), а не строка значения. Тест меряет верх строки текста;
  наложения нет (низ лейбла 19, текст с 24 по дизайну).
- **file-upload — контраст текста неактивной dropzone (4×).** Дефект компонента: disabled-группа
  не объявляла себя неактивной, а read-only гасилась так же, как disabled. Теперь корень
  disabled-группы несёт `aria-disabled="true"` (axe исключает неактивный контент), read-only
  dropzone не гаснет (класс `--inactive` → `--disabled`, только для disabled).
- **file-upload — группа с описанием.** Неверное допущение: `name: 'Attachments'` без `exact`
  совпадал и с «Disabled attachments». Добавлен `exact: true`.
- **file-upload — фокус после удаления строки.** Найден **старый дефект** (не этой переработки):
  удаление строки вызывает `cancel` → `schedule()` в `useFileUploadQueue.ts`, и не запущенные
  пользователем строки начинают загружаться; кнопка Start следующей строки превращается в Cancel
  и исчезает вместе с фокусом. Не чинился — тест помечен `test.fixme` с объяснением, вопрос ниже.
- **autocomplete — открытая панель не открывается по `.focus()` (6×).** Неверное допущение после
  решения Q4 → 2 (`openOnFocus: 'pointer'`): тест открывает панель кликом.
- **dropdown — половина строки (0.55 vs 0.5) и начало текста строки (2.5 > 2).** Тайминг: панель
  открывается со scale, строки мерились посреди анимации (зонд: 0.81 → 0.51 → 0.50 за 1 с).
  Хелпер `openWithKeyboard` ждёт `waitForMotion`.
