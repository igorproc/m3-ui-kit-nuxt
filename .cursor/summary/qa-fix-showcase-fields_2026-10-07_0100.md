# QA-аудит: витрина — поля и кнопка (фаза D)

**Даты:** 2026-10-06 — 2026-10-07
**Предыдущие шаги:** `qa-fix-infra-and-bugs_2026-10-06_1900.md`, `qa-fix-global-styles_2026-10-06_2300.md`.
**Как делалось:** три агента в отдельных worktree по общему брифу (`.cursor/summary/runs/phase-d-brief.md`,
лежит локально, не в git). Их ветки перенесены в main через cherry-pick.

## Сквозные решения пользователя (общие для всех полей)

- **Q6 — ошибка в forced colors.** Рамка пунктирная, цвета `CanvasText`, а не `Mark`.
- **Q7 — фокус старше ошибки.** На рамке фокус показывается всегда. Ошибку сообщают лейбл, текст и
  иконка. Поля в read-only тоже показывают фокус.
- **Q8 — `aria-invalid`.** Ставится только при видимой ошибке, `!meta.valid` больше не учитывается.
- **Q9 — `inheritAttrs: false`.** Всё, кроме `class` и `style`, уходит на нативный контрол через
  `useControlAttrs`. Собственный набор атрибутов компонента объединяется с атрибутами потребителя
  через `mergeProps`, поэтому слушатели обоих срабатывают по цепочке.
- **Адаптер vee-validate остаётся.** Удаление было предложено и откатано по решению пользователя.

## Что сделано по компонентам

- **button** (вся семья):
  - loading больше не меняет ширину, фокус не выглядит как нажатие;
  - segmented — это radio group для одного выбора и набор toggle-кнопок для нескольких;
  - у split появилось имя кнопки меню, кольцо фокуса не обрезается;
  - в dev появилось предупреждение, если у кнопки нет доступного имени.
- **otp-input:**
  - клик попадает в нужную ячейку;
  - вставка сначала очищается от лишних символов и только потом обрезается по `maxlength`;
  - контейнер `role="alert"` смонтирован всегда, место под строку ошибки зарезервировано;
  - слушатели потребителя объединяются со слушателями поля, `loading` теперь работает.
- **text-field:**
  - у filled в состоянии error и disabled окрашивается только нижняя граница (раньше рисовалась красная рамка
    со всех сторон);
  - строка поддержки всегда зарезервирована, в ней постоянный alert и иконка ошибки;
  - 0 считается значением, обязательность обозначена `*`, `aria-busy` следует за состоянием pending;
  - добавлены `:autofill`, RTL и слоты `helper`/`error`.
- **textarea:**
  - live-регионы смонтированы всегда, счётчик символов объявляется только у самого лимита;
  - grip стал больше и получил disabled-состояние;
  - добавлены RTL и `:autofill`, шкала отступов, токены движения;
  - **headless API изменился:** `supportAttrs`/`counterAttrs` → `{ id }`, добавлены `alertAttrs`,
    `counterLiveAttrs` и `counterAnnouncement`.
- **number-input:**
  - Enter отправляет форму, Escape отменяет правку;
  - у кнопок-степперов есть `aria-controls` и `aria-describedby`;
  - для unit-переключателя доступное имя содержит видимую единицу;
  - у scrub есть состояние перетаскивания;
  - добавлены RTL, `:autofill`, шкала отступов, forced colors для степперов;
  - зона единицы занимает не больше 30% ширины поля.

## Волна 2 — dropdown и autocomplete (агент)

- Клавиатура по WAI-ARIA APG:
  - type-ahead с буфером 500 мс;
  - Home/End открывают список и ставят на цель, PageUp/PageDown перемещают на ±10, Alt+↑/↓.
- `role="listbox"` содержит только опции. Прогресс и тексты состояний вынесены рядом.
  Постоянный `role=status` в поле объявляет состояния.
- Курсор клавиатуры отображается как `focus-ring(inset)`, наведение мышью — слоем 10%.
- Добавлены `inheritAttrs: false` и `overscroll-behavior: contain`; длинные заголовки переносятся.
- Новые composables: `useDropdownKeyboard`, `useTypeahead`, `usePanelStatus`. Стили панели
  вынесены в общий `dropdown/_panel.scss`, и оба SFC теперь короче 400 строк.
- Исправил после слияния: `:aria-busy` в MTextField перетирал значение из `inputAttrs`.

## Видимые изменения, которые стоит проверить глазами

- **Все поля теперь всегда резервируют строку поддержки (~22rem).** Это касается и композитов:
  HEX-поля color-picker, поля в dialog/date, dropdown и autocomplete в плотных тулбарах.
- Кнопка в состоянии loading без иконки показывает только спиннер по центру.
- Длинные подписи segmented переносятся на новую строку.
- Ячейки OTP сжимаются в узком контейнере.
- Scrub у number-input, RTL у всех полей, `:autofill` в Chrome и Safari.

## Открытые вопросы

Полный список с вариантами — в отчётах агентов и в финальном сообщении сессии. Ключевые:

- aria-disabled и фокусируемая loading-кнопка (IN-08);
- фокус полностью заполненного OTP;
- когда впервые показывается ошибка (FM-04, общий `useField`);
- политика английских строк по умолчанию (CT-13);
- размер stacked-степперов меньше 24px (RS-06);
- `inputmode` у отрицательных чисел на iOS;
- ключ `disabled-fill: 4%` в общей шкале;
- непрозрачность футера textarea;
- кольцо фокуса у grip;
- общий миксин `:autofill`;
- `letter-spacing` в миксине `typescale`.

## Межкомпонентные долги (не тронуты)

- MMenu оборачивает listbox в поверхность с `role="menu"` (axe `aria-required-children`), держит
  слушатели document, пока закрыт, и возвращает фокус на `anchorRef.parentElement` и игнорирует проп `anchor`.
- `placementToArea` не учитывает RTL. `usePopover` не перемеряет высоту панели и не
  ограничивает её доступным местом (LY-05/RS-10).
- `npm run test:e2e` работает на фиксированном порту 3200 с `reuseExistingServer`, это небезопасно
  для параллельных worktree.
- Нестабильный `useModal.spec` под нагрузкой: для него есть отдельная задача-чип.
