## Волна B (три параллельных агента)

- **Layout** (B3.*, N.5, N.8, B5.2b): main скроллит только в `full-height` (`m-layout-main--scroll`, Tab-стоп из
  SSR), иначе `overflow-x: clip` — sticky работает; `container` у main — по пропу; `m-layout--nested`;
  `m-layout-item` требует `kind`; `insets.start/end`; `ui-app-bar--sticky`, `headingLevel`; малый бар без
  `padding-block`; снекбар/меню без `<client-only>`-плейсхолдера; rail `--hosted` только в боковой зоне.
  Новый `composables/layout/zone.ts`; `docs/layout.md` переписан.
- **Навигация** (B5.*, N.1, Q24): пресет `v-model` MTabs верен в SSR; имя tablist, id панелей, RTL-стрелки;
  rail/bar плоские, непрозрачная таблетка, `select` на каждую активацию; drawer `side: start|end`, скролл,
  `#activator`; toolbar `role`/`aria-pressed`/иконка+подпись; `softDisabled` у MButton/MButtonIcon — Prev/Next
  пагинации и подвал MTable держат фокус; пагинация без английских дефолтов, `pageLabel`, kebab-ключи
  слотов; крошки через `scroll-initial-target`. Новые фикстуры: tabs, pagination, navigation, breadcrumbs (49 e2e).
- **Поля** (A6, решение владельца «CSS-переменные — только у layout»): `--ui-text-field-*`, `--ui-textarea-*`,
  `--ui-number-input-*`, `--ui-scrollbar-inset-*` убраны; оси — статический Sass под `:where(… *)`. Вид не
  изменился (14 400 комбинаций осей, A/B-скриншоты). Цена: CSS трёх полей 53 → 132 КБ, gzip 7,7 → 10,5 КБ
  (по дампу агента; prod не сверен).

Остались только `--ui-*` размеров зон layout и рантайм-мосты (`--ui-slider-*`, `--ui-menu-origin`,
`--ui-fab-*`, `--ui-table-fade`, `--m-textarea-rows`).

## Ломающие изменения (в changelog 0.6.0)

(`--m3-layout-inset-inline-*`); `kind` обязателен у `m-layout-item`; `container` у `MLayoutMain` по пропу

`MNavigationRailItem` передаёт событие; `aria-controls` у вкладок только с панелями.

## Баг реестра (после волны B, по просьбе владельца)

- Корень: `useId()` вне setup возвращает `''`; поздние регистрации без `id` во всех слоях
  (`createRegistry`, `createModel`, `createSelection`, `createGroup`, через них `createSingle`) получали
  один id, второй тикет подменялся первым.
- Фикс: `createTicketIds()` в `utils/registry/internals.ts` — в setup `useId()`, вне setup — префикс
  реестра (его `useId()` при создании) + счётчик. Спек `composables/registry/ticketIds.spec.ts` (7 тестов,
  6 падали до фикса). vitest 2230/2230.
- Цена: каждый реестр берёт один `useId()` при создании — номера `v-…` дальше по дереву сдвигаются;
  сервер и клиент делают это одинаково.
- e2e после фикса: 917/18/4. Два «новых» падения — нестабильные тесты, не регрессия:
  axe `time-picker` (dark, rtl) проходит при повторе; `search … docked view … as wide as the bar` —
  гонка в тесте: `waitForMotion` возвращается до старта перехода меню и меряет поверхность в начале
  появления (384 → 480 за ~250 мс). На сборке **без** фикса тот же тест упал 1 раз из 3 — гонка старая.
  Тест — в WIP владельца (search v2), не тронут.
