# The system / Система

The kit's constitution: the decisions that are no longer taken per component. Read it before
designing or refactoring a component.

Конституция кита: решения, которые больше не принимаются на уровне отдельного компонента.
Читать перед проектированием или переработкой компонента.

Both locales carry the same rules. When a decision changes, update both — a rule that exists
in one language only is not a rule.

Обе локали содержат одни и те же правила. Меняется решение — правь обе: правило,
существующее на одном языке, правилом не является.
